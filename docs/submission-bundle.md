# Submission Bundle Checklist

## Baseline summary

- **Project:** Leftover Chef.
- **Problem:** Help home cooks turn leftover ingredients into practical Indian-inspired meals.
- **Working features:** Veg/non-veg ingredient category with automatic recipe filtering; ingredient checklist; local recipe matching; manual 3-item mode and exact-three judge presets with optional compatible suggestions; no-match explanation; prep and cook time; advance-prep note; zero-waste score with visible calculation and score guidance; nutrition/cost/saved-value estimates; recipe sorting; use-soon priority; cooking mode; tips; dark mode; first-visit guide with replay control; judge presets.
- **Preview:** Open `index.html` in a modern browser or serve the project folder with a static file server. No secrets or private services are needed.
- **Known limits:** Prototype recipe data, keyword matching, illustrative (not verified) nutrition and cost values, no allergy or medical dietary support, no account or server-side persistence; only the intro completion flag is stored locally in the browser.
